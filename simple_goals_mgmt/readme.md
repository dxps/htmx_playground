## Simple Goals Mgmt

This is an example of managing goals, just like a todo list, as a way to understand HTMX.

</br/>

## Start

First, install the Node dependencies using `npm install`.

Then, you can start the back-end (a Node.js app that uses Express) in "dev mode" (restart on changes) using `npm start`.

And you can go to http://localhost:3010/ to access the UI.
